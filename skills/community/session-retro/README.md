# session-retro

End-of-session retrospective. Mines the current conversation for errors, repeated patterns, user corrections, knowledge gained, and workflow friction; suggests memory entries, new skills, skill improvements, and hooks; applies whatever the user picks.

Install:
```bash
jutsu install session-retro
```

Trigger phrases: "retro", "session retro", "what did we learn", "extract learnings", "before we wrap up".
