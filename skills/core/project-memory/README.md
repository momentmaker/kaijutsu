# project-memory

Cross-skill contract for the per-project memory directory. Defines the schema (frontmatter + body), the directory layout (`MEMORY.md` index + topic files), the type taxonomy (`user` / `feedback` / `project` / `reference`), and the read/write/dedupe/remove rules.

Composed by `decide`, `session-retro`, `unstuck`, `journal`, `agent-doctor` — any skill that accumulates persistent knowledge.

Install:
```bash
jutsu install project-memory
```

Trigger phrases: "project memory", "memory schema", `/project-memory`.
