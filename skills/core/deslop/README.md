# deslop

Strips AI-generated tells from a draft — emdash overuse, formulaic contrasts ("It's not X, it's Y"), pseudo-profound openers ("At its core..."), hollow connectors, bullet explosions, trailing summaries — without changing the substance.

Used by `polish`, `journal`, `readme-update`, and any skill that produces user-facing prose.

Install:
```bash
jutsu install deslop
```

Trigger phrases: "deslop", "remove AI tells", "make this sound less like ChatGPT", `/deslop`.
