# unstuck

Guided problem articulation when you're stuck. Forces the user to articulate goal/expected/actual/attempts, then offers structured pivots and an escalation ladder. Captures the root cause to memory once the problem is solved.

Install:
```bash
jutsu install unstuck
```

Trigger phrases: "unstuck", "I'm stuck", "this isn't working", "help me think through this", "I keep going in circles", `/unstuck`.
